Your hybrid project involves deploying on-premise server hardware (predictive) alongside a custom cloud management software portal (agile). During Sprint 4, the software product owner requests a significant change to the user authentication workflow to meet a new security standard. The hardware procurement phase is already locked.

What is the best immediate path for the project manager to protect the project baseline?

* A. Direct the agile team to implement the change in the next sprint and issue a retrospective change request.
* B. Halt all software sprints until the change control board (CCB) formally reviews and approves the change.
* C. Analyze the impact of the software change on the locked hardware milestones and present the findings to the change control board (CCB).
* D. Reject the product owner's request as the hardware baseline is already finalized and cannot be modified.
